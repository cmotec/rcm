# Database schema

PostgreSQL (external), managed with Alembic (`backend/alembic/versions`). Source of truth:
`backend/app/models.py`. Conventions: UUID primary keys (generated by the application),
`timestamptz` everywhere, enumerations as `varchar` + `CHECK`, `*_enc` = AES-GCM ciphertext
(`bytea`), `version` for optimistic concurrency.

```
users ─┬─< user_roles >── roles ──< group_role_mappings
       ├─< user_groups >── groups
       ├─< web_sessions          (cookie hash → user; encrypted OIDC tokens)
       ├─< api_tokens            (hash only)
       ├─< favorites >── connections
       └── user_preferences      (JSON, incl. saved workspace layout)

folders ──< folders (parent_id)
folders ──< connections (folder_id)        connections ──< connections (parent_id)
credentials ──< credentials (parent_id)    credentials ──< connections (credential_id)
acl_entries (resource_type, resource_id, principal_type, principal_id, permission)

secret_providers ──< secret_mappings >── credentials
secret_providers ──< sync_runs
known_hosts · audit_events · session_records · app_settings · import_jobs · idempotency_keys
```

## Tables

| Table | Purpose | Notable columns / constraints |
|---|---|---|
| `users` | accounts (OIDC and local) | unique `lower(username)`; unique (`oidc_issuer`, `oidc_subject`); `password_hash` (Argon2id, local only); `is_signage` + `signage_connection_id` (FK, `SET NULL`) for signage displays |
| `roles` | built-in (`admin`, `user`, `readonly`) and custom roles | `permissions text[]`, `resource_cap` (highest resource permission) |
| `user_roles` | membership | `source` = manual / oidc / bootstrap (IdP-derived roles are replaced at each login) |
| `groups`, `user_groups` | IdP groups seen at login | usable as ACL principals |
| `group_role_mappings` | IdP group → role (in addition to env mappings) | unique (group_name, role_id) |
| `web_sessions` | browser sessions | `id` = SHA-256 of cookie; `expires_at`, `last_seen_at` (idle), `csrf_token` |
| `api_tokens` | personal access tokens | `token_hash` unique, `read_only`, `expires_at`, `revoked_at` |
| `folders` | hierarchy | `parent_id` (RESTRICT), `icon`, `color`, `search_domain`, `version`; authentication for inheriting connections: `auth_mode`, `username`, `domain`, `password_enc`, `credential_id` (RESTRICT), `credential_folder_id` |
| `connections` | connection definitions and host nodes | `protocol` ∈ host/ssh/sftp/rdp/vnc/ftp/ftps; `folder_id` **xor** `parent_id`; `auth_mode` ∈ inherit/direct/credential/interactive (credential without `credential_id` = chosen at connect time); `inherit_auth`; `password_enc`; `credential_id`; `search_domain`; `tags text[]` (GIN index); `settings jsonb` (validated per protocol); `lookups jsonb` (field → `{{lookup:…}}`); `credential_folder_id` (limits the credential choice); `import_source jsonb` |
| `credentials` | credential store | all fields optional; `password_enc`, `private_key_enc`, `passphrase_enc`; `parent_id` inheritance; `folder_id` → `credential_folders`; `attributes_enc` (encrypted JSON: values for lookups, shown to viewers); `secret_attributes_enc` (encrypted JSON, write-only); `metadata jsonb`; `rotation_interval_days`, `secret_changed_at` |
| `personal_accounts` | a user's own logins (Profile → My accounts) | `user_id` (cascade), `kind` `user`/`privileged` (unique per user), `username`, `domain`, `password_enc` (write-only); only the owner can use them |
| `credential_folders` | folder tree of the credential store | `parent_id`; grants via `acl_entries` with `resource_type = cred_folder` |
| `acl_entries` | resource grants | `resource_type` ∈ folder/connection/credential/cred_folder (all-zero UUID = root); `principal_type` ∈ user/group/role; `permission` ∈ view/connect/edit/manage; unique per (resource, principal) |
| `known_hosts` | trusted SSH host keys | unique (hostname, port, key_type); `fingerprint` (SHA256), `public_key` |
| `secret_providers` | OpenBao (Vault-compatible) | `config jsonb` (non-secret), `secret_config_enc`, `managed_by_env`, sync status |
| `secret_mappings` | credential field ← external secret | `field` = a credential field, `attr:<name>` (an attribute) or `secret:<name>` (a secret attribute); unique (credential_id, field); `external_ref jsonb`; `conflict_policy`, `delete_policy`; `remote_hash`/`local_hash` (SHA-256 fingerprints for change detection); `pending_remote_enc` (value waiting for conflict resolution) |
| `sync_runs` | sync history | `stats jsonb`, `status`, `error` |
| `audit_events` | audit log | bigint identity; `actor_*`, `action`, `resource_*`, `outcome` ∈ success/failure/denied, `ip`, `request_id`, `details jsonb` (redacted); indexes on ts, actor+ts, resource, action |
| `session_records` | session history (no secrets) | effective host/port, `auth_sources`, start/connect/end times, `end_reason` |
| `app_settings` | admin-editable runtime settings | key/value JSON |
| `user_preferences` | per-user JSON | workspace layout, UI preferences |
| `import_jobs` | RDM import previews and reports | `preview jsonb`, `result jsonb`, `status` |
| `idempotency_keys` | stored responses for `Idempotency-Key` | unique (user_id, key); purged after 24 h |

## Integrity rules enforced by the database

* No item can be its own parent (folders, connections, credentials). Deeper cycles are rejected
  by the API (`would_create_cycle`).
* A connection lives either in a folder or under a parent connection, never both.
* Deleting a credential, folder or parent that is still referenced fails (`RESTRICT`). The API
  reports what references it.
* Port range 1–65535.

## Migrations

```bash
python -m app.cli migrate                    # upgrade to head (also done at start-up)
alembic -c backend/alembic.ini revision --autogenerate -m "…"   # developers
```
